# SGPA & CGPA Academic Calculator

A fast, client-side single-page application for calculating approximate SGPA per semester (Sem 1, Sem 2, Sem 3) and cumulative CGPA.

## Features

- **Semester 1 & 2**: Grade dropdowns with credit-weighted SGPA calculation.
- **Semester 3**: Continuous Assessment (CA1–CA5) + Attendance percentage evaluator and specialized Partner Company project/viva scoring.
- **Persistent Overall CGPA**: Live cumulative average updated on every input.
- **Zero Backend**: All inputs and calculations are saved automatically to `localStorage`.
- **Modern Responsive UI**: Clean 100% full-width design with green and white theme.

## Getting Started

Simply open `index.html` in any modern web browser or host on GitHub Pages / Vercel / Netlify.
